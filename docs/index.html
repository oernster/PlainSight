The documents you wrote
are invisible.

They sit in folders you rarely open. They accumulate quietly: some written months ago, most long out of mind. You cannot review what you cannot see. PlainSight walks a folder of Markdown, text, HTML, Word and PDF files, shows it as the tree it is on disk and renders the one you pick. It reads nothing until you choose a folder; the chooser opens on your home directory, which asks no permission of you.

What it reveals

Things you own
but have never read.

A folder of documents grows the way a drawer fills. Nothing announces itself, nothing asks to be reviewed, so the writing you rely on most is the writing you have never gone back to. PlainSight opens the drawer.

  • What is actually here. Not what you meant to write: what is on this machine, right now, folder by folder.
  • What each one still says. Rendered to read, with the fields it declares laid out plainly.
  • Where it lives. The tree mirrors your folders exactly, each one carrying a count so a shut branch tells you whether it is worth opening.
  • Your Claude skills, if you keep them. Point it at that folder and the plugins tree beside it comes too, as a second root, so the skills you wrote and the ones that arrived with a plugin stay apart.
  • What is broken. A file that cannot be read is still listed, with the reason shown rather than quietly dropped.
Everything it does

Your folders as they are, with nothing chosen until you choose it.

Looking changes nothing.

PlainSight never writes to a document. That is not a promise made in a readme: a structural test reads the whole program and fails the build if any part of it but the settings file calls a writing operation. When you want to change something, it hands the document to the editor you chose and stands back.

Supporting PlainSight

PlainSight is free and stays free. There is no paid tier, no licence key and no feature held back behind a donation. If it has shown you something you needed to see, a contribution supports its maintenance and continued development. The same button sits in the window's own bottom tray.
