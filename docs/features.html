Features

Everything it does.

All of it in service of one thing: showing you a set of documents you own but have never seen together.

Finding them

  • Looks in the usual place for your operating system, with no configuration to do first.
  • Browse to any other folder instead; the choice is remembered for next time.
  • A skill is a directory holding a SKILL.md. A loose SKILL.md at the top of the tree counts as one too.
  • Directories with no skill document, along with hidden and cache directories, are passed over rather than listed as empty entries.
  • Plugin skills are read from the tree beside your skills folder, at whatever depth they sit.

Telling them apart

  • Skills you wrote and skills that arrived with a plugin are listed under a heading each, so ownership is never a guess.
  • Each group opens and closes with an arrow; Enter or Space works it from the keyboard.
  • A group you close stays closed when the library is read again.
  • Where everything came from one place there is nothing to separate, so the headings do not appear at all.
  • The plugin a skill came with is named on the skill itself.

Reading one

  • The selected skill is rendered to be read, not shown as raw text.
  • The fields it declares are laid out plainly; an oversized field gets a heading of its own after the body rather than crowding the top.
  • The other files sitting beside the document are named, so a multi file skill says so.
  • A skill whose frontmatter will not parse is still listed, with the failure shown in the pane rather than raised as a dialog.
  • The text column is held to a readable line length, so a wide window gives margins rather than longer lines.
  • The page reads itself gently down and hands control straight back the moment you scroll.

Reading it your way

  • Light and dark, switched from the tray and remembered between runs.
  • Three text sizes, stepped by one button that always shows the size it would move to.
  • Changing either keeps your place: you stay on the words you were reading rather than being thrown to the top.
  • Full keyboard navigation, as one explicit ring that wraps at both ends.

Editing, elsewhere

  • Open the selected skill in the editor you choose; on Windows one is already picked for you.
  • The control stays disabled until there is genuinely something to do: a skill selected, an editor chosen and that editor still where you left it.
  • Come back to the window and the library is re-read, so an edit made outside shows up without a refresh button.
  • It never writes to a skill itself, which a structural test enforces rather than leaving to discipline.

Staying current

  • Asks GitHub whether a newer release exists, a few seconds after opening and once a day after that.
  • It speaks only when there is something to download. Ask from the Help menu and it answers either way.
  • Skip a release and it is never mentioned again; the next one still reaches you.
  • That is the only request it makes of its own accord; nothing about you goes with it.
