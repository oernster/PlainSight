Windows

Windows 10 or 11, 64-bit

Download for Windows

Setup program (.exe)

Windows may show a SmartScreen warning when you run this: here is why.

Run the setup program. It installs for the current user under your local application data, offers Desktop and Start Menu shortcuts and registers itself so it uninstalls the ordinary way.

🐧

Linux

Any flatpak desktop, 64-bit

Download for Linux

Flatpak bundle (.flatpak)

Install with flatpak install --user skillsviewer.flatpak. It runs sandboxed. It is granted your home folder so it can read your skills, plus network access for the update check; nothing else.

🍎

macOS

macOS on Apple Silicon

Download for macOS

Disk image (.dmg)

Open the disk image and drag Skills Viewer into Applications.

From source

Python 3.11 or newer, then:

git clone https://github.com/oernster/SkillsViewer.git
cd SkillsViewer
python -m pip install -r requirements.txt
python main.py
