Free and open source, the user interface under LGPL-3.0 and the model under GPL-3.0. Installed per user on every platform, so no administrator rights are needed. No account, no cloud: the only request it makes of its own accord is asking GitHub whether a newer release exists.

Windows

Windows 10 or 11, 64-bit

Download for Windows

Setup program (.exe)

Windows may show a SmartScreen warning when you run this: here is why.

Run the setup program. It installs for the current user under your local application data, offers Desktop and Start Menu shortcuts and registers itself so it uninstalls the ordinary way.

🐧

Linux

Any flatpak desktop, 64-bit

Download for Linux

Flatpak bundle (.flatpak)

Install with flatpak install --user plainsight.flatpak. It runs sandboxed. It is granted your home folder so it can read the documents you point it at, plus network access for the update check; nothing else.

🍎

macOS

macOS on Apple Silicon

Download for macOS

Disk image (.dmg)

Open the disk image and drag PlainSight into Applications.
