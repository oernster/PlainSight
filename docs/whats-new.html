What's new

Recent releases have focused on what a document can make PlainSight do. The newest keeps pictures to this computer, sends a link only where you would expect it to go and keeps updates and imports on GitHub; the Linux Flatpak can no longer change your home folder. Before that PlainSight learned to import a GitHub repository's release notes as a folder of Markdown, to count what you are reading and to hide what is not yours to read. It began as Skills Viewer, a window onto your Claude skills, then became a reader for Markdown, text, HTML, Word and PDF.

v2.6.0

Pictures and links stay where you would expect

  • A picture in a document is read from this computer only. One named on a network share is no longer read, so a document somebody sent you cannot make your computer reach a machine it names
  • A picture named relative to its document, such as images/picture.png, is now looked for in the document's own folder instead of going unshown or coming from wherever PlainSight started
  • A web or email link goes to your browser or mail program and a link within the page moves you there; every other kind of link now does nothing
  • A file of your own in an imported release notes folder no longer hides a later release that would have taken its name
  • The update check and the release notes import follow a redirect only while it stays on GitHub
  • The Linux Flatpak sees your home folder read only; the one folder it may write to is its own
v2.5.0

A website with a page for each part

  • The site's features page gives the short version, then hands over to a page on what PlainSight reads and one on how the tree and the reading page work
  • The site's stylesheet is named by its content, so a browser never pairs a fresh page with a stale stylesheet
  • An update check answering after its window has gone is now dropped quietly instead of raising an error on a background thread
  • For anyone building from source: the Windows and macOS builds need Nuitka 4.2.1 or newer and say so before touching anything; development, testing and decision documents join the README
v2.4.0

Import a GitHub repository's release notes

  • A new button in the top tray turns any public GitHub repository's release history into a folder of Markdown, opened on the newest release with the rest listed newest first
  • Each file opens with the release's title, its tag, a link back to GitHub and a clear mark for a pre-release. A release published with no notes still gets its page
  • Paste the address however you have it: the full address, owner/repository or a page inside the repository. Anything that names no repository is refused before GitHub is asked
  • Importing again brings the folder up to date and keeps any file you have edited exactly as you left it; a refresh that fails leaves every file readable
  • Errors say what went wrong in words, including when GitHub's hourly allowance comes back. An import can be cancelled while it reads
  • PlainSight still never writes to a document you point it at. The import is its second kind of network request, made only when you ask for one
v2.3.3

A new donation page

  • The Donate button now opens a new PayPal page that suggests £5 and lets you give any amount you choose. Nothing else has changed
v2.3.2

Diagrams and code blocks read properly

  • A diagram drawn with box characters now joins up into one clean rectangle, where its lines came out as dashes in a ragged staircase
  • Prose still stops at a comfortable line length. A diagram or a block of code spreads into the window's full width and scrolls sideways only when the window is too narrow to show it whole
v2.3.1

Tooltips show while another program has focus

  • Every window, its dialogs and the setup program included, now shows its tooltips whether it is the active one or not
v2.3.0

A status bar for what you have open

  • The foot of the window names the kind of document at the left and counts its characters and lines at the right
  • The count is of the text you are reading rather than the bytes of the file; a document that could not be read still names its kind
v2.2.1

The donate link follows the new name

  • The donation button's link now refers to the app by its new name, PlainSight
v2.2.0

The tree hides what is not yours to read

  • venv and node_modules folders are hidden, as are documents holding nothing to read and any folder that leaves empty
  • One button at the right end of the bottom tray turns the filter off and on. Its picture shows the filter as it stands; the choice is remembered between runs
  • A PDF, a document that cannot be read and a file opened on its own are never hidden
v2.1.0

The chooser opens on your home folder

  • The folder chooser opens on your home directory, the one starting place no operating system asks you to approve, instead of the Claude skills folder
  • Uninstalling now removes PlainSight's settings too, so a later install starts fresh. Your documents are never touched
  • Three statements in the documentation were corrected against the code
v2.0.0

Skills Viewer becomes PlainSight, a reader for documents

  • Skills Viewer read a folder of Claude skills. Renamed PlainSight, it now reads a folder of documents or a single file
  • Five kinds of file: Markdown, plain text, HTML, Word and PDF. A PDF is read back into headings, emphasis and lists from the size and face of its lines
  • A scanned or password-protected PDF says so instead of showing an empty page
  • A Guide, first on the Help menu, names every picture in the two trays and says what each kind of document becomes in the reading pane
  • Scripts inside a document are dropped rather than run and nothing is fetched on a document's behalf; the update check stays the one request of its own
  • A folder is listed without reading every file: forty twelve-page PDFs list in 7 ms where reading them all took 515 ms
  • Nothing is read until you choose a folder, the left pane is the tree your folders actually are and a new button opens a single document
  • The Linux build works again; the macOS image ships the licence files
v1.0.0

Skills Viewer: see the skills Claude reads

  • Finds your Claude skills, lists them on the left and renders the one you pick on the right. Skills you wrote and skills that came with a plugin are grouped apart
  • Long text is set to be read: a readable line length, space between paragraphs and long passages broken between sentences, with nothing added or removed
  • Light and dark themes plus three text sizes, with your place in a skill kept across a change of either
  • The reading pane reads itself down slowly and hands control back the moment you touch it. Every control is reachable through one keyboard ring
  • Editing is handed to an editor you choose; Skills Viewer never writes to a skill
  • An update check a few seconds after opening and once a day, silent unless there is something newer. It is the one network request of its own
  • A per-account Windows setup program, a Linux Flatpak and a signed macOS disk image
